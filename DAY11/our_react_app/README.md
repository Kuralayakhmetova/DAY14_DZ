📌 Описание проекта

our_react_app — учебное React-приложение, демонстрирующее работу с компонентами, состоянием и динамическим рендерингом данных. Интерфейс приложения строится на основе данных без использования статической разметки для повторяющихся элементов.

🛠 Используемый стек технологий

React

JavaScript (ES6+)

HTML5

CSS3

Node.js

npm

🚀 Запуск проекта локально

Клонируйте репозиторий:

git clone https://github.com/Kuralayakhmetova/our_react_app.git

Перейдите в папку проекта:

cd our_react_app

Установите зависимости:

npm install

Запустите проект:

npm start

Откройте в браузере:

http://localhost:5173/
